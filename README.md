## 💎 Architecture & Features

1. **Clean Root Domain**: Configured directly on `https://shubh-creations.github.io/` without any subfolder paths.
2. **Stark Editorial Minimalism**: Pure OLED black `#000000`, delicate hairline borders (`rgba(255, 255, 255, 0.08)`), and crisp typographic hierarchy.
3. **Subtle Monochrome Particles**: Lightweight 60fps canvas particles responding to cursor attraction.
4. **Typographic Metrics Ledger**:
   - `1.2M+` Active Users Scaled
   - `$1.8M+` Historical Scaled ARR
   - `99.99%` Infrastructure SLA (&lt;20ms p99)
   - `12,400+` GitHub Stars
5. **Interactive SAFE Allocation Calculator**: Range slider ($25K–$500K) dynamically computing equity %, runway extension, and milestone impact.
6. **Neural Digital Twin**: In-browser AI console providing verified answers to investor questions.
7. **8-Slide Pitch Deck Reader**: Keyboard navigable (`←` / `→` / `Esc`) slide presentation.
8. **Command Palette (`⌘K` / `Ctrl+K`)**: Fast fuzzy search menu with keyboard shortcuts.
9. **Audio Haptic Engine**: Pure Web Audio API synthetic feedback (muted by default with HUD toggle).
10. **Print / PDF 1-Pager**: Press `Ctrl + P` to export an ink-friendly executive brief.
